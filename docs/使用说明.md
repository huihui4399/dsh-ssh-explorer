# SSH 远程资源管理器 — 完整使用手册

**插件名**：`dsh-ssh-explorer`
**版本**：`1.7.0`
**安装位置**：`%USERPROFILE%\.dsh\profiles\desktop\plugins\dsh-ssh-explorer`
**能力**：文件浏览 + 每连接独立口令 + AI 对话流式回复 + 可拉伸停靠栏 + 分组模型下拉 + 底部远端终端 + 双向拖拽传文件 + 选中/多选/删除 + 右键新建与重命名。

> 版本历史见 [CHANGELOG.md](../CHANGELOG.md)；快速上手与安装见 [README.md](../README.md)。

---

## 一、它是什么

对标 VSCode 的「SSH 远程资源管理器」，但做成了 DSH 自带侧栏里的一个面板：

- 侧栏图标（活动栏）里多一项 **远程资源管理器**
- 面板里可以 **配置 SSH 连接**（名称 / 主机 / 端口 / 用户名 / 私钥），也可以直接 **读 Windows 的 `~/.ssh/config`** 自动导入现成主机
- 列出远端目录、点进去浏览、面包屑回退、↑ 上级、⌂ 家目录
- 点文件名在右侧 **只读预览**（文本直接显示，二进制给提示，大文件截断）
- 顶部显示远端 `主机名 / 系统 / Python 版本`
- **拖拽传文件**：远端的东西拖出窗口就下载到桌面，本机的东西拖进来就上传到当前远端目录（见 §二「拖动传文件」）
- **单击选中 / `Ctrl` 加选 / 整批拖出**：选中的一批可以一起传到桌面；`Delete` 或右键菜单删远端文件与文件夹（见 §二「选中、多选与删除」）
- **右键新建 / 右键重命名**：列表空白处右键可以建空文件或空目录，选中一条右键可以就地改名（见 §二「新建与重命名」）
- 面板右上角 **✦ AI 对话**：跟模型说话，它自己调 SSH 工具去在远端读写文件、跑命令（见 §二）

不需要在 Ubuntu 上装任何东西 —— 它走的是 Windows 自带的 `ssh.exe` 加远端自带的 `python3`，
传文件夹再借远端自带的 `tar`（GNU tar，Ubuntu/Debian/CentOS 都预装）。
远端只需要能被 SSH 登录（本机 `ssh ubuntu` 已经配好免密）。
AI 对话走的是 DSH 桌面版**自带的本地模型网关**（`http://localhost:7863/v1`），也不需要你额外配 API。

## 二、重启后怎么用

1. **完全退出 DSH 再打开**（客户端插件只在启动时加载一次；只关窗口到托盘不算）
2. 左侧活动栏应该多出一个 **远程资源管理器** 图标（在靠下的位置，`order: 50`）
3. 点它打开面板。如果连接下拉里已经有 `ubuntu` / `192.168.111.129`，那是从 `~/.ssh/config` 自动读到的，直接选一个就能浏览
4. 想加自己的连接：点 **＋ 新建连接**，填完保存

### 口令（每台机器各自一套，互不影响）

每台主机的口令是**分开存**的，改一台不会影响另一台。三种入口：

| 场景 | 怎么做 |
|---|---|
| 新建连接时就知道口令 | 在「＋ 新建连接」表单里，**认证方式**选 `只用密码`（或 `自动`），在 **密码** 栏填一次 |
| 已经连过、后来才知道要口令 | 选中这条连接 → 操作栏点 **🔑 设密码**（已有口令时显示 **🔑 改密码**） |
| 连的时候才发现要口令 | 面板顶部会直接出现「这台主机要口令」的输入框，填一次 → **保存口令并重试** |

- 从 `~/.ssh/config` 自动读到的连接同样是**可写**的：它们是只读的「连接定义」，但**口令照样能单独设**（点 🔑 就行）。所以 `ubuntu` 要口令也拦不住你。
- 口令用 **Windows DPAPI（CurrentUser 作用域）加密**后存在 `~/.dsh/ssh-explorer/secrets.json`；只有你这台机器、你这个账户能解开，拷到别的机器或别的账户就是一堆废字节。
- 认证方式有四种：`自动`（先试密钥再试密码）、`只用密钥`、`只用密码`、`ssh-agent`。**编辑连接时密码栏留空 = 不改动已存的口令**（想清掉请用 🔑 里的「清除密码」）。
- 只想改个名字或端口时，密码栏不用管，留空提交即可。

### AI 对话（直接在远端写代码）

面板右上角工具栏有一个 **✦ AI 对话** 按钮。点一下**不会顶掉文件页**，而是在**右侧推开一个可拉伸的对话栏**；再点一次（按钮变成 **✦ 收起对话**）就收起来。

- **拉伸**：文件页和对话栏之间那条竖线可以拖，**往左拖对话栏变宽**（最小 280px）。
- **文件列表 ⇄ 预览**之间也有一条竖线，**往右拖列表变宽**（最小 240px）。
- 两条宽度都记在 `localStorage`，下次打开还是上次那个宽度。
- 对话栏标题栏右侧有 **✕** 可以直接收起。

- **用法**：直接说要干什么，它会**自己**调 SSH 工具去读目录、读文件、跑命令、写文件，然后把结果讲给你听。不用你指定用哪个命令。
- **能举的例子**：
  - `在 /home/admin/demo 下写一个 hello.py 打印当前时间，然后用 python3 跑一遍给我看输出`
  - `看一下 /etc/nginx/nginx.conf 里 worker_processes 是多少`
  - `列一下 /var/log 里最大的 5 个文件`
  - `df -h 输出贴给我，顺便说说哪个分区快满了`
- **它会用的工具**（就这 4 个，模型自己挑）：

  | 工具 | 干什么 |
  |---|---|
  | `ssh_list` | 列目录（含权限、大小、时间） |
  | `ssh_read` | 读文本文件（二进制会被挡） |
  | `ssh_write` | 写文件（走 SSH stdin 流式传，自动建父目录，覆盖前留 `.re-bak`） |
  | `ssh_exec` | 跑任意 shell 命令 |

- 轮次里每次工具调用的**命令和输出都会显示在气泡下面**（🔧 那行 + 灰底输出块），所以你随时能看到它到底干了什么，不会黑箱。
- **它用的是哪条模型链路**：DSH 桌面版自带的**本地模型网关** `http://localhost:7863/v1`（OpenAI 兼容协议，监听进程是 `wb2api`）。模型默认 `cn:deepseek-v4.1-flash`，密钥从 `~/.dsh/.credentials.yaml` 的 `refs: WB_API_KEY` 读。
  - 想换模型/网关：建一个 `~/.dsh/ssh-explorer/chat.json`，写 `{"baseURL": "...", "model": "...", "apiKey": "..."}`，优先级高于上面的默认值。
- **自己挑模型**：对话栏标题栏有一个**模型下拉**，**列的就是你在 DSH「设置 → 模型」里配过的那些**，按提供商分组：
  - 宿主会去读 `~/.dsh/profiles/<profile>/cordis.patch.yml` 里 `llm-pi-ai.config.providers` 那段，把每个提供商的 `models[]` 连同显示名（`name`）取出来。
  - 本机实测：`wb · 6 个模型`（Deepseek-V4.1-Flash / Deepseek-V4-Pro / Hy4 preview / Space-Bunny / Kimi-K3 / Auto）+ `gpt · 4 个模型`（gpt-6.1-sol / gpt-6-sol / gpt-6-luna / gpt-5.6-sol）+ `网关其余模型 · 13 个`（网关有、但没配进 DSH 的那部分），合计 **23 个**。
  - **换提供商时 baseURL 与密钥会一起切过去**：选了 `gpt-*`，请求就打 `http://localhost:50409/v1` + `GPT_API_KEY`；选了 `cn:*` 就打 `http://localhost:7863/v1` + `WB_API_KEY`。不用手工建 `chat.json`。
  - 选完**本次会话立刻生效**（之后每次请求的 body 都带 `model`），同时**落盘到 `~/.dsh/ssh-explorer/chat.json` 当新默认值**——重启 DSH 也还是它。
  - 鼠标悬停下拉能看到「模型：xxx / 已存为默认 / 可选提供商」。
  - 如果上一轮实际用的模型和你现在选的不一样，标题栏会多出一行灰字 `实际：xxx`（例如中途换过、或某轮请求失败）。
  - 网关连不上时下拉不会空着，用宿主内置的 19 个模型清单兜底；读不到 profile 配置（没有 `yaml` 包 / 文件结构不认识）就退回平铺在同一个下拉里，不会报错。
  - 想改回默认：把 `~/.dsh/ssh-explorer/chat.json` 里的 `model` 删掉即可。
  - ⚠️ 提供商本身要在线：截至 2026-10-11，`wb`（7863）在跑，`gpt`（50409）**没在跑** —— 选 `gpt-*` 会报 `连不上模型网关 http://localhost:50409/v1（模型 gpt-6.1-sol）：fetch failed`。这个报错里带电口地址，就是为了让这种情形一眼可查。
- **开销上限**：一次提问最多跑 **10 轮**工具循环；发给模型的历史只保留最近 **24 条**、每条最多 40000 字符；单次工具输出最多回灌 6000 字符（超了会截断并标注）。
- **实测性能**：真机一次「列出 /home/admin 里以点开头的项」= **1 次工具调用、4.3 秒**。
- **对话不会存盘**：刷新页面或切走就没了。要留东西就让它在远端写文件。

#### 回复长什么样（1.2.0 起）

观感对齐 DSH 本体：**边生成边显示**，不是等半天再一次性吐出来。

- **流式**：客户端走 `POST /chat` 带 `stream:true`，宿主回 `text/event-stream`。事件顺序 `round` → `thinking`（思考逐片来）→ `thinking-done` → `tool-start` / `tool`（每轮工具）→ `reply`（正文逐片来）→ `done`。正文末尾有个闪烁光标，回复没结束就一直在。
- **思考过程保留**：思考单独成一个折叠块，抬头写「🧠 思考中…」，结束后变成「🧠 已深度思考（N 字）」。**流式期间自动展开**；你自己点过之后就不再自动收放（点开就一直开着，点收就一直收着）。
- **工具调用是卡片**：抬头**只有一行** —— `🔧 $ 命令…` 人话摘要，命令里的换行和连续空格会折成单个空格，超过 72 字符截断成 `…`（再用 CSS `text-overflow: ellipsis` 兜一层，窄面板也不会撑开）。**点开**才看完整命令、参数（`content` 只显示字符数）与输出；鼠标悬停在抬头上，`title` 里也给全文和「N 行输出」。抬头上这一步的输出行数一直显示着，所以收起状态也知道这次跑了多大的东西。失败的话边框转红、图标变 `✖`。
- **正文按 markdown 渲染**：围栏代码块（右上角带语言标签 + **复制**按钮）、行内代码、粗体斜体、标题、无序/有序列表、引用、分隔线、表格、链接。渲染器是插件自己写的，零依赖、不用 `innerHTML`（远端回来的文本一律当纯文本处理，不会执行）。
- **退路**：万一宿主是老版本、或者响应不是 `text/event-stream`，客户端自动退回一次性 JSON 路径，照样能看回复（只是没有流式效果）。

### 底部远端终端（1.2.0 起）

工具栏最右边有一个 **⌨ 终端** 按钮，点开在面板**底部**推开一个终端条（再点变成 **⌨ 收起终端**）。

- **拉伸**：终端和上面的内容之间有一条横线，**往上拖终端变高**（默认 220px），高度记在 `localStorage`。
- **用法**：输入命令敲回车。`↑` / `↓` 翻历史（最多留 100 条），`cwd` 会跟着命令里的 `cd` 走并在抬头上显示；非 0 退出码会额外标一行红色的「（退出码 N）」。
- **退出码与 cwd 是真的**：宿主在远端命令外面套了一层 —— 先 `cd <上次的目录> || cd "$HOME"`，再挂一个 `EXIT` trap 打出 `\001MARK\001<退出码>\001<结束时 pwd>\001`。**用 trap 而不是命令后面追加 printf**，是为了让 `exit 3`、`exec` 这类把 shell 换掉的情况也能拿到退出码和最终目录。
- **一条命令一次 SSH**，**不是真 PTY** —— 所以 `vim`、`top`、`less` 这类需要终端交互的程序**跑不了**（会直接报 `not a terminal` 或者行为错乱）。要看文件用 `cat` / `sed -n`；要长驻的服务用 `nohup … &` 或 `systemd`。
- 命令长度上限 8000 字符；超时默认 **120 秒**（请求里可给 `timeoutMs`，上限 1 小时），超时和「trap 没跑到」是两种不同的报错，便于区分。
- 实测（`test_host.mjs` 第 12 节，真机真 SSH）：基本命令、退出码 0、默认回传 cwd、`cd` 后 cwd 变了、cwd 累积到下一条、`exit 3` 真的是 3、`false` 是 1、stdout 与 stderr 分开、标记没漏进 stdout、cwd 不存在回落 HOME、多行原样、引号与 `$` 原样、超时返回失败、空命令 400、超长命令 400、未知连接 404、GET 405、跨站 403。

### 拖动传文件（1.3.0 起；1.5.0 起界面上只剩拖动）

**远端 → 本机**（落点固定为**桌面**）

| 手段 | 说明 |
|---|---|
| 选中文件/文件夹后 **拖出窗口**松手 | 一条 → 拖那一条；先用 `Ctrl` 多选 → **整批**一起传 |
| 行尾 **⬇** / 右键菜单「下载到桌面」 / 预览页「下载」 | 等价入口，行为相同 |

**本机 → 远端**

| 手段 | 落到哪 |
|---|---|
| 从资源管理器把文件/文件夹**拖到列表空白处** | 当前远端目录 |
| **拖到某个目录行上**（目录行会高亮） | 那个目录里 |
| 先选中远端多行再拖进目录行 | 选中的整批同时上传（逐个串行） |

> 1.5.0 起工具栏的「⬆ 上传 ▾」、ops 行的「⬇ 下载此目录」、右上角「落点」下拉**都已撤掉**，
> 界面上不再有上传/下载按钮 —— 上传只能从 Windows 资源管理器拖进来，下载只能拖出去（或用行尾 ⬇ / 右键）。

**看进度**：右下角 **⇅ 传输** 打开抽屉，每个传输一条：`下载 / 上传` + 阶段（准备 / 传输 / 写入 / 完成）+
`已传字节 / 总字节` + 逐项结果；运行中可 **取消**，跑完可 **在资源管理器中显示**。

要点：

- **落到本机的是真实文件夹**，不是 zip：远端 `cd <父目录> && tar -cf - -- <名字>` 流过来，插件**自己**解 tar 写到落点目录（用 JS 解，不依赖 Windows 的 `tar.exe` —— 它解出来的中文名是乱码，见 §九）。中文名、嵌套目录、二进制内容、mtime 全部原样保留。
- **上传文件夹**时，如果拿到的是本机真实路径（桌面版有 `__DSH_HOST_PATHS__` 桥），就直接交给宿主读目录树 → 自己打成 tar → 远端 `tar -xf -`；拿不到路径才退回逐个文件走字节流（慢，但浏览器里也能用）。
- **同名不覆盖**：落点/远端已有同名文件或文件夹时，这一项标红「本机已有同名文件/文件夹（可在设置里允许覆盖）」，不动原文件。
- **原子落盘**：每个文件先写 `<名字>.re-dl-tmp` 再 `rename`，取消或断线不会留下半个文件（实测取消后落点目录干净）。
- **传输走宿主侧任务队列**，不占 HTTP 请求：所以拖一个 180MB 的目录不会把面板卡住，进度是轮询出来的。

> **为什么「拖出窗口」不是系统级拖放**
> DSH 的 Electron 壳把浏览器下载整个禁掉了（`app.asar` 里 `will-download` 直接 `preventDefault()`），
> 页面也拿不到 `webContents.startDrag`（壳没暴露）。所以「拖出窗口」在实现上是：
> 拖动时把远端路径写进 `text/plain`，**指针离开窗口**（`relatedTarget === null`）后松手 = 替你把这份东西传到落点目录。
> 效果一样是「文件出现在桌面上」，但不能像资源管理器那样把文件丢进别的应用窗口。

### 选中、多选与删除（1.5.0 起）

| 操作 | 效果 |
|---|---|
| **单击**一行 | 选中它（文件顺带在右侧预览）。**单击不再进目录** |
| **`Ctrl` + 单击** | 加选 / 取消这一条；选多条时**列表左下角浮出**一条 `已选 N 项 · Ctrl+点击加选 · 拖出去=下载`（1.6.1 起是浮条，不占布局，选中时文件不会往下跳） |
| **双击目录** | 进入该目录（双击文件 = 重开预览） |
| 拖动选中行 | 拖的是**整批**（见上一节的批量传输） |
| **`Delete`** 键 | 删掉选中的一批（先弹确认框） |
| **右键** | 菜单三项：`⬇ 下载到桌面` / `🗑 删除` / `取消选择`；在未选中的行上右键会先把选中换成这一行（跟资源管理器一致） |

- 删除**一定二次确认**：确认框写明「删除 N 项？」并列出名字、提示远端删除不可恢复。
- 宿主 `POST /delete` 逐条执行、逐条报结果：一条失败不影响其它条，客户端把失败的第一条名字与原因显示在顶部红条里，列表随后自动刷新。
- 安全栅栏写在 `DELETE_PY` 里：拒绝删 `/`、拒绝删家目录本身；删不存在的路径算成功（幂等）；符号链接只删链接本身。
- 多选只对「一次性动作」有意义：换目录、切连接、重连都会清空选中。

### 新建与重命名（1.6.0 起）

两种动作都从**右键**进，共用同一个「输入名字」小浮层：

| 在哪儿右键 | 菜单 | 做什么 |
|---|---|---|
| 列表**空白处** | `📄 新建文件…` / `📁 新建文件夹…` | 在**当前目录**里建一个空文件或空目录；建完自动选中它，方便接着拖或改名 |
| 选中的**一条** | `✏️ 重命名…`（外加下载 / 删除 / 取消选择） | 就地改名：`os.replace` 语义，原有内容、权限、mtime 全跟着走 |
| 选了**多条** | 没有重命名项 | 一次只改一个名字，多选时只给 `⬇ 下载` / `🗑 删除` |

浮层的键盘与校验：

- `Enter` = 确定，`Esc` = 取消（输入过程中直接按，不用先点按钮）。
- 名字为空 → 就地提示「名字不能为空」，**不发请求**。
- 名字带 `/` 或 `\` → 就地提示「名字里不能带路径分隔符」，**不发请求**（避免建到别的目录里去）。
- 重名 → 宿主回 409 `{"ok":false,"error":"已存在同名文件或文件夹"}`，原因原样显示在浮层里，浮层不关。
- 改名时新名字与旧名字相同 → 宿主直接返回 `unchanged: true`，不动文件。

宿主两条端点（都只改远端，本机不落任何东西）：

```text
POST /create   { connection, dir, name, kind: "file" | "dir" }
             → { ok, path, kind, existed }       400 名字不合法 / 500 Create
POST /rename   { connection, path, name }
             → { ok, path, from, unchanged }     409 撞名 / 400 拒绝重命名根目录
```

安全栅栏在 `CREATE_PY` / `RENAME_PY` 里：拒绝在 `/` 根目录新建东西、拒绝把 `/` 或家目录本身改名；
远端路径一律先 `os.path.abspath(os.path.expanduser(...))` 归一化，再判断父目录是不是 `/`。

### 删除不再需要的设备（1.4.0 起）

工具栏的 **🗑 管理连接** 会摊开一个浮层，里面是**全部**连接（不管来自自建还是 `~/.ssh/config`），每条都标了来源：

| 连接来源 | 点「删除」之后 |
|---|---|
| 自建连接（面板里 ＋ 新建的） | **真删**：从 `connections.json` 移除，连带删掉它存的口令 |
| 来自 `~/.ssh/config` | **只从清单隐藏**：你的 `~/.ssh/config` 一个字节都不动（想彻底清掉某台机器，请自己编辑那个文件） |

- **二次确认**：第一下「删除」只是把这条变成 `确认删除 / 取消`，第二下才真动手 —— 防止误点。
- 删掉的连接不会消失，而是落到浮层底部的 **「已删除（N）」** 分组里，每条右边有 **恢复**。
- 隐藏是**持久**的：写在 `~/.dsh/ssh-explorer/hidden.json`，重启 DSH 依然是隐藏状态；
  宿主那边 `mergedConnections()` 与 `resolveConnection()` 都会跳过它，所以对已隐藏的连接发请求会得到 404。
- 被隐藏的连接**连不上、也列不出目录**，等于真的从面板里没了；但随时能一键恢复。
- 删掉的正好是当前正连着的机器时，面板会自动切到剩下的第一台，列表清空。
- 单个连接的操作条上也直接有「删除」（同样二次确认），不必每次都开管理浮层。

### 编辑远端文件（改完直接保存）

右侧预览窗格不再是只读的了 —— 点开一个文本文件，标题栏右边有 **编辑** 按钮：

1. 左侧文件树点一个文件 → 右边出现内容预览
2. 点预览标题栏的 **编辑** → 变成可改的编辑框（内容已经在里面）
3. 改完按 **Ctrl+S**（或点 **保存**）→ 直接写回远端
4. **取消** 或 **Esc** 退出编辑，不写盘

几个要点：

- **改动过但没保存时**，标题栏会出现 **未保存** 徽标；保存成功后徽标消失，下方变绿显示「已保存 N 字节 · 原文件备份为 …」。
- **保存前会自动备份**：原文件在同目录复制一份 `<文件名>.re-bak`。存错了就用它回滚（`mv x.py.re-bak x.py`）。
- **写入是原子的**：先写 `<文件名>.re-tmp` 再 `os.replace` 顶替，中途断网不会留下半个文件。
- **权限位会保住**：原本 700 的脚本存完还是 700。
- **超过 512 KB 的文件不给编辑入口**（预览会被截断）。这时按钮不出现，改显示「文件超过 512.0 KB，只显示了开头一部分，不能在这里编辑。」—— 这是故意的：草稿只有开头一段，存回去等于把文件锯短。
- 二进制文件（预览显示「二进制文件，无法预览」）同样没有编辑入口。
- 内容走的是 **SSH 的 stdin 而不是命令行**，所以多大的文本都不会被 32767 字符的命令行上限截断（实测 86916 字节的文件写回逐字相同）。

**如果重启后没看到图标**，先跑这条检查（只读，不改任何东西）：


## 六、安全说明（重要）

本机 profile 里有一段托管配置把 web 服务绑到了 `0.0.0.0`（那是 `dsh-remote-web-ui` 为了局域网访问加的），
所以**这个插件的 HTTP 接口在局域网里是可达的，而它能读远端任意文件**。
加了「编辑 + 保存」之后它还能**改**远端文件 —— `POST /write` 可以覆盖那台机器上当前用户可写的任何路径。
（缓解措施：覆盖前一律留 `<文件名>.re-bak` 备份，而且改动是原子替换。）

因此 `index.js` 里加了一道栅栏 `originAllowed(req)`：

- 带 `Sec-Fetch-Site: cross-site` 的请求一律拒
- 带 `Origin` 头时，必须和 `Host` 同源
- 两个头都没有（非浏览器客户端，如 curl）放行

**局限**：curl 类客户端可以绕过这道栅栏；它能防的是「你浏览器打开了恶意网页，那个网页偷偷用你的 DSH 接口读你远端文件」这类 CSRF。
如果不需要局域网访问，最彻底的做法是把 profile 里 webserver 的 `host: '0.0.0.0'` 改回 `127.0.0.1`。

另外，插件只允许读写**连接配置里那台机器的、当前用户有权限的**路径 —— 没有提权，也没有绕过 SSH 自身的权限模型。

**关于 AI 对话**：`POST /chat` 是这批端点里权限最大的一个 —— 模型可以借它在那台远端机上**跑任意命令、写任意文件**。
所以它和别的端点共用同一道同源栅栏，并且：

- 对话页只能操作**面板当前选中的那台连接**，模型拿不到连接清单，也不能换机器
- 它用的工具和文件页用的是**同一套** `sshExec` / `remotePython`，没有额外提权
- 对话历史**不落盘**，每次请求由前端整段带上（所以宿主半边不持有会话）
- 网关请求在宿主进程里发，密钥不出现在浏览器侧

如果你不想让这条链路存在，可以在 `~/.dsh/profiles/desktop/cordis.patch.yml` 的 `[ssh-explorer]` 块里加上 `chat: false`：

```yaml
- insert:
    - id: ssh-explorer
      name: './plugins/dsh-ssh-explorer/lib/index.js'
      config:
        rev: 9
        chat: false        # ← 加这一行，重启后 AI 对话整条链路关掉
```

关掉之后：`/chat` 直接返 403，文件页工具栏上的 **✦ AI 对话** 按钮也不显示，文件浏览完全不受影响。

## 七、已知限制

| 限制 | 说明 |
|---|---|
| 拖出不是系统级拖放 | 壳把「浏览器下载」整个禁了（`will-download` → `preventDefault()`），页面也拿不到 `webContents.startDrag`；所以「拖出窗口」= 让宿主拷到落点目录，不能把文件丢进别的应用窗口 |
| 拖入必须松手在面板上 | 拖到 DSH 其它区域会被壳当成 `@路径` 芯片塞进输入框（面板里已经 `preventDefault` 拦住了自己这块） |
| 传输是单流串行 | 一次拖一批会按顺序传；没有多路并发、没有断点续传 |
| 界面上没有上传/下载按钮（1.5.0 起） | 传文件只能拖动：上传从资源管理器拖进面板，下载拖出窗口（行尾 ⬇ / 右键「下载」是等价入口）；落点固定为桌面 |
| 单击不再进目录 | 单击 = 选中、双击才进目录；习惯了旧行为的话会觉得「点一下没反应」 |
| 只能建空文件 / 空目录 | 新建不给填内容（建完在预览里「编辑」写），也不支持一次建多层目录 |
| 重命名一次只改一条 | 多选时菜单里不出现重命名；也不支持批量前缀替换之类的规则改名 |
| 删除不可恢复 | 有二次确认，但没有回收站 / 撤销 |
| 预览上限 512KB | 超过就截断；**被截断的文件不给编辑入口**（防止存回去把文件锯短） |
| 编辑是整文件覆盖 | 没有多光标/语法高亮/查找替换，就是个 `<textarea>`；大文件不适合在这里改 |
| 不保存密码 | ~~密码登录每次都得输~~ —— **已实现每连接独立口令**（DPAPI 加密，见 §二） |
| 面板标题是中文写死的 | 界面切英文时这一项仍显示「SSH 远程资源管理器」 |
| 依赖 Windows 的 `ssh.exe` | 没有它时面板会明确提示 `找不到 ssh 可执行文件` |
| AI 对话依赖本地模型网关 | 桌面版自带的 `wb2api`（`localhost:7863`）不在跑时对话会报错，文件页不受影响 |
| AI 对话不保存历史 | 切页/刷新即丢；要留东西就让它在远端写文件 |
| AI 对话是单轮串行 | 一次提问内部最多 10 轮工具循环，中途不能插话；也没有「停止」按钮 |

## 九、这次踩到的坑（留给下次）

1. **PS 5.1 的 `Set-Content -Encoding UTF8` 会写 BOM** → 改 `cordis.patch.yml` 必须用 Python 以 `utf-8`（不带 BOM）写字节
2. **中文 Windows 上 Python `subprocess.run(..., text=True)` 默认按 GBK 解码** → 读 node 的 UTF-8 中文输出会抛 `UnicodeDecodeError`，必须显式 `encoding="utf-8", errors="replace"`
3. **`cordis.patch.yml` 里有 `!!js` 自定义 tag** → 用标准 yaml 解析器校验前要先 `replace(/!!js\s+/g, "")`
4. **本地插件条目用相对路径时，`dsh-client-modules` 靠 `nearestPackage()` 从入口文件往上找 `package.json`** → 所以 `./plugins/<名>/lib/index.js` 这种写法一样能带客户端半边
5. **`main` 是 keyed slot**，键在 `options.key`，且必须和 `sidebar.panellist` 的 `id` 一致才能联动；同一个 key 注册两次会抛
6. **给面板加 state 只能追加在最后**：`test_client.mjs` 的迷你 React 是按**调用顺序**分配 hook 槽位的，
   我在 `ExplorerPanel` 里插了一个 `useState` 之后，测试里那些 `runtime.set(10, …)` 就全指错了位置 ——
   报出来的症状是「发送按钮一直是禁用」「错误文案串进了别的槽位」。
   现在的槽位顺序（**共 40 个**）：`0 state / 1 preview / 2 showForm / 3 info / 4 editing / 5 secretFor / 6 authInput / 7 authBusy / 8 view / 9 listWidth / 10 chatWidth / 11 termOpen / 12 termHeight / 13-15 effect / 16 loadConnections / 17 browse / 18-19 effect / 20 draft / 21 dest / 22 localDirs / 23 jobs / 24 drawerOpen / 25 dropTarget / 26 dragRef / 27-31 effect / 32 manageOpen / 33 pendingDelete / 34 selected / 35 rowMenu / 36 confirmDelete / 37 namePrompt（新建/重命名的输入浮层）/ 38 effect(Del 键) / 39 effect(换目录清选中)`，
   所以 `ChatPanel` 的 `messages` 从 **40** 开始、`input` 在 **41**。测试里已经固化成常量：
   ```js
   const SLOT = 40;            // ExplorerPanel 占用的 hook 数，**加了 hook 就要改这个**
   const EDIT_DRAFT_SLOT = 20; // 编辑草稿
  const PROMPT = 37;          // 「输入名字」浮层（新建 / 重命名共用）
   const CHAT_INPUT = SLOT + 1;
   ```
   > 提醒：`dest`(21) 在 1.5.0 之后已经没有界面入口了（落点固定桌面），但槽位**不能删** —— 删掉会让后面整体前移。
   下次再动 hook，先 `process.env.DBG` 打印一遍槽位（`test_client.mjs` 里有现成的调试块）。
7. **`react.useRef` 也要进测试替身**：迷你 React 原本只实现了 `useState/useCallback/useEffect`，
   加了 `useRef` 的组件一渲染就 `react.useRef is not a function`。
8. **连接对象上名字的字段是 `name`，不是 `label`**：文件页用 `name`，我一开始在对话页写成 `connection.label || connection.host`，
   结果顶栏只显示 IP。现在写成 `label || name || host` 三档兜底。
9. **`apply(ctx, config)` 的第二个参数才是插件 config**：想让插件能被 `cordis.patch.yml` 里的 `config:` 配置，
   签名必须写成 `apply(ctx, config)`（我原来只写了 `apply(ctx)`，config 直接被丢了）。config 存在模块级变量里，
   `test_host.mjs` 里再调一次 `apply(ctx, {chat:false})` 就能验证开关生效。
10. **Windows 命令行上限 32767 字符** → 传文件内容**必须走 stdin**，走 argv 必被截断。
    用 `spawn` + `child.stdin.end(buffer)`；注意 `spawn` 没有 `timeout` 选项（那是 `execFile` 的），
    要自己 `setTimeout` 杀进程并把 `error.killed = true` 置上，才能沿用 `sshExec` 里已有的超时判定逻辑。
11. **远端脚本用 `python3 -c "$(printf %s <b64> | base64 -d)" <路径>`，不要用 `python3 - <路径>`**：
    只有 `-c` 才能把 python 的 stdin 留给文件内容（`-` 会把 stdin 当成脚本本身吃掉）。
12. **`SAVE_PY` 一开始漏了 `target.parent.mkdir(parents=True, exist_ok=True)`**：
    报错是 `[Errno 2] No such file or directory: '/tmp/dsh-re-edit/hello.py.re-tmp'` ——
    注意报的是 **tmp 文件**而不是目标文件，因为 `open(tmp, 'wb')` 是第一个失败点，容易被误判成「路径算错了」。
13. **`rev` 是客户端 bundle 的缓存破坏版本号**：改了 `lib/client.js` 就要把它 +1（`install.py` 里的 `BLOCK` 模板），
    否则浏览器可能继续吃旧的 `client.js`。改法是 `python install.py --rollback` 再 `python install.py`
    （install.py 对已存在的补丁块是**跳过**的，不会自动更新版本号）。
14. **断言不能用 `textOf(tree).includes("编辑")`**：预览区的引导语「点左侧文件名即可预览，预览后可以点「编辑」直接改」里也有「编辑」二字，
    会把「只读连接不该有编辑按钮」这条断言打成假失败。判按钮要用 `buttonByText(tree, "编辑")`。
15. **测试要能重复跑**：第 12 节第一次跑完之后远端留下了 `hello.py`，第二次跑「新建时 existed=false」就失败了。
    现在节开头先 `rm -rf /tmp/dsh-re-edit`。**任何「新建」类断言前面都得先清场。**

### 1.3.0 新增的坑（拖拽传输）

16. **Windows 自带的 `C:\Windows\System32\tar.exe` 不能用来解包**：它是精简版 bsdtar 3.8.9，
    `--hdrcharset=UTF-8` 直接报 `Option --hdrcharset=UTF-8 is not supported`，解 GNU tar 写出的
    UTF-8 中文名会变成乱码（`中文 目录` → `涓枃 鐩綍`），因为它按系统 ANSI 代码页（GBK）解释文件名。
    → 最后**自己用 JS 写 tar 读/写器**（读：`Buffer.toString("utf8")`，支持 GNU `@LongLink` 与 pax；
    写：ustar 头 + `././@LongLink` 放长名字），远端只用 `tar -cf -` / `tar -xf -` 当搬运工。
17. **DSH 的 Electron 壳把下载整个禁了**：`app.asar` 里 `browserSession.on("will-download", (e) => e.preventDefault())`，
    所以 `<a download>`、`fetch → blob → 下载` 一律无效；`startDrag` / `setSavePath` / `showSaveDialog` 也都没暴露。
    → 传输必须**在宿主侧写盘**（Node 拿流写文件），页面只负责发起与看进度。
18. **远端 python 脚本别再走 `python3 -`**：`printf %s <b64> | base64 -d | python3 - <目标>` 会把 **stdin 当脚本本身吃掉**，
    文件内容一个字节都进不来（症状：远端出现 0 字节文件，返回值 `{"ok":true,"bytes":0}`）。
    → 改成 `python3 -c 'import base64,sys;exec(base64.b64decode(sys.argv[1]))' <b64>`，
    目标路径 / mtime / 是否覆盖一律走**环境变量**（`RE_TARGET` / `RE_MTIME` / `RE_OVERWRITE`），stdin 干干净净留给数据。
19. **绝不要用 PowerShell 改 UTF-8 源码**：`(Get-Content -Raw) -replace … | Set-Content -Encoding utf8`
    会把文件里的中文全毁成 mojibake（它已经按 GBK 读进来了，再按 UTF-8 写出去，双重错）。
    同理 PowerShell 管道/`Out-File` 传二进制 tar 流也会毁包（会得到假的 `Unrecognized archive format`）——
    要重定向二进制就用 `cmd /c "ssh … > file"`。改源码一律用编辑工具，别用 shell 做字符串替换。
20. **测试里别写死 IP 或 `ubuntu` 别名**：换网段/改 `~/.ssh/config` 之后，
    `ssh ubuntu …` 会直接 `Could not resolve hostname`，把整份测试**中途崩掉**（而且 `[FAIL]` 计数是 0，看着像全绿）。
    → 现在从 `/connections` 里挑 `source === "ssh-config"` 的第一台，`RE_TEST_HOST=<别名>` 可覆盖，
    临时命令统一走一个 `sshRun()` 帮助函数（带 `-p` / `-i`）。

### 1.6.0 新增的坑（右键新建 / 重命名）

21. **新 hook 的槽位未必是你以为的那个位置**：我在 `confirmDelete` 之后加了 `selected`/`rowMenu`/`confirmDelete`/
    `namePrompt`，后面又补了两个 `useEffect`。结果 `namePrompt` 落在 **37**、两个 effect 是 **38/39**；
    测试里按「它在最后」写成 `runtime.set(39, …)`，症状是「浮层明明渲染出来了，`peek(39)` 却是 `null`」——
    因为点到了 effect 的槽位。→ 测试里固化成 `const PROMPT = 37;` 这种**具名常量**，别写裸数字。
22. **测试里点菜单项要取「最里层」那个节点**：右键菜单的卡片 div 本身也挂着 `onClick`（只为 `stopPropagation`），
    而它的 `textOf` 里同样含「新建文件」，`collect()` 先序遍历会先命中卡片 —— 点下去等于没点。
    → 用一个 `menuItem(source, label)` 帮助函数，按命中节点文案长度**升序**取最短那个。
23. **`/create` 与 `/rename` 的远端脚本同样走 `python3 -c` 引导**（同 §18），参数一律走 argv：
    `remotePython(connection, SCRIPT, [路径…])` 里路径的中文与空格由 `shq()` 单引号转义。
24. **改名要保「原子性 + 元数据」**：`os.replace` 原地改名才保得住 inode 上的 mtime/权限；
    用「复制 + 删源」会把 mtime 改掉。撞名判断要在 `os.replace` **之前**做，别指望它自己报错。
25. **「新建」类断言每轮都要先清场**（同 §15）：`test_transfer.mjs` 的 `/tmp/re-e2e/mut` 每轮 `rm -rf` 重建，
    否则第二次跑时 `existed` 变 `true`、`/create` 直接 409，一堆用例假红。

### 1.6.1 新增的坑（选中浮条）

26. **别把「有时才出现的条」塞进 `flexWrap: "wrap"` 的工具栏**：选中栏原来插在 ops 行（`S.bar` + `flexWrap`）里，
    一选中就把那行挤成两行，**下面 29 个文件整体下移一格**，看着像列表在跳。
    正确做法是**绝对定位的浮条**（`position: absolute` + 挂在 `position: relative` 的浏览区里），
    外加给列表一个 `paddingBottom`，让最后几行能滚到浮条上方 —— 布局高度一个像素都不变。
27. **浮条要给 `zIndex`**：它和拖放高亮 `dropOverlay`、传输抽屉、右键菜单背板同层，没写 `zIndex` 会被盖住。
28. **断言「不挤布局」要断言样式，不能只断言文案**：只测「已选 2 项」出现在页面上是测不出跳动的；
    要额外断言浮条 `style.position === "absolute"`、ops 行文本里**不含**「已选」、列表 `paddingBottom` 的变化。
